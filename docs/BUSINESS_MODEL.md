# Aegis Business Model

## Overview

Aegis is a Google Workspace administration tool with a freemium model:

| Product | Price | Description |
|---------|-------|-------------|
| **Aegis Client** | Free | Self-host forever. Open source (BSL license). |
| **Aegis Cloud** | Coming Soon | Managed hosting. We run it for you. Monthly fee. |
| **Donations** | Optional | Support development via Stripe (one-time or recurring). |

---

## Aegis Client (Free, Open Source)

**License:** BSL (Business Source License)

Self-hosted Google Workspace admin portal. Users download the code and run it on their own infrastructure.

**What users get:**
- Full Google Workspace administration features
- User management, groups, email signatures
- Complete control of their data
- Community support via GitHub

**What we provide:**
- Open source code
- Documentation
- GitHub Discussions for community support

**Revenue:** None (open source)

---

## Aegis Cloud (Coming Soon)

**Status:** Waitlist open at api.obilabs.dev/waitlist

Managed hosting where we run Aegis for customers.

**What we will provide:**
- VPS infrastructure
- Automatic updates
- SSL certificates
- Daily backups
- Application support

**What we will NOT do:**
- Access customer admin panels
- View customer data
- Manage their Google Workspace directly

**Revenue:** Monthly subscription fee (pricing TBD)

---

## Donations

**Status:** Active at api.obilabs.dev/donate

Support project development via Stripe.

**Options:**
- One-time donations ($5, $10, $25, $50, or custom)
- Monthly recurring donations

**Features:**
- Donors can opt to display name on credits page
- Custom display names supported
- Anonymous donations supported

---

## How This Site Fits In

Aegis-web (this project) is the **marketing site and cloud portal**:

1. **Marketing** - Landing page, features, pricing info
2. **Waitlist** - Collect signups for Aegis Cloud launch
3. **Donations** - Accept payments via Stripe
4. **Credits** - Show supporters publicly
5. **Support Chat** - AI-powered support via Gemini
6. **Telemetry API** - Collect anonymous usage stats from instances
7. **License Validation** - Validate licenses (for future paid tiers)
